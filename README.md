# Student Course Registration System API

Academic student enrollment, course cataloging, and prerequisite verification API.

## Features
- Course offering management, seat capacity, and schedule conflict validation.
- Student profile and enrollment history tracking.
- Prerequisite check before registration confirmation.

## Tech Stack
- Java 21 LTS
- Spring Boot, Spring Data JPA
- MySQL 8.0
- Maven Wrapper

## Running
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
